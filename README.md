## The entry

`main.py` writes one single hilarious line to `/output/entry.txt`:

> My Roomba filed for divorce, citing irreconcilable dirt, and took the couch in the settlement.

94 characters, one line, no trailing newline. The joke is concrete
(a Roomba, a divorce filing, the couch it kept getting stuck under),
the twist lands in the last few words, and every word earns its place.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: the same fixed string every run, no input, no randomness,
no network, no environment secrets. Requires only Python 3 (stdlib only).
